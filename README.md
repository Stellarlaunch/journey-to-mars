# Journey to Mars — An Interactive Odyssey

## Project Description
Journey to Mars, An Interactive Odyssey is a visually engaging web experience that simulates a cinematic journey from Earth to Mars. The project aims to involve users through storytelling, animations, and interactive features, making space exploration easy and fun.

The website has several sections, each representing a different stage of the journey. It starts with an animated introduction based on Earth, followed by a rocket launch sequence with lively visuals and a countdown simulation. As users scroll down, they enter a space travel phase where a distance tracker shows the journey from Earth to Mars, along with interesting space facts.

The Mars landing section presents users with a stylized view of the Martian surface, featuring visual effects like dust storms and terrain details. The final exploration section shows interactive cards that highlight different aspects of Mars exploration. Users can engage through hover animations and modern UI design.

This project uses HTML and CSS, focusing on effective styling, smooth transitions, and responsive design. It pays special attention to typography, color schemes, and animation timing to create a modern and unified experience.

This project showcases strong frontend development skills, especially in UI/UX design, animation, and storytelling. It blends education and visual design to provide a unique view of space exploration through a web-based platform.
